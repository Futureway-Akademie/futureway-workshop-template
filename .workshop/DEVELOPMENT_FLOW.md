# Entwicklungsablauf

```text
IDEA
  → PROJECT BRIEF
  → ROADMAP
  → TASK SELECTION
  → USER PROMPT
  → IMPLEMENTATION
  → VERIFICATION
  → PROGRESS UPDATE
  → NEXT TASK
```

## IDEA

Der Teilnehmer beschreibt frei, was er entwickeln möchte. Solange keine Idee vorliegt, wird keine Anwendung implementiert.

## PROJECT BRIEF

Agent und Teilnehmer schärfen Ziel, Zielgruppe, Kernfunktionen, Nicht-Ziele, Rahmenbedingungen und die Definition of Done.

## ROADMAP

Das Vorhaben wird in geordnete Phasen und kleine, prüfbare Tasks mit Abhängigkeiten zerlegt.

## TASK SELECTION

Der Teilnehmer wählt aus den laut Roadmap startbaren Tasks. Der Agent empfiehlt einen nächsten Task, entscheidet aber nicht ungefragt.

## USER PROMPT

Der Teilnehmer beschreibt Funktionen, Verhalten, Gestaltung und besondere Anforderungen für den ausgewählten Task.

## IMPLEMENTATION

Der Agent setzt ausschließlich den ausgewählten Task und notwendige kleine Abhängigkeiten um.

## VERIFICATION

Die Umsetzung wird gegen ihre Definition of Done geprüft. Relevante Tests werden tatsächlich ausgeführt und wahrheitsgemäß dokumentiert.

## PROGRESS UPDATE

Roadmap, abgeleiteter Fortschritt, Aktivitätsprotokoll, aktueller Stand und relevante Dokumentation werden konsistent aktualisiert.

## NEXT TASK

Der Agent zeigt die jetzt möglichen Folgetasks aus der Roadmap. Anschließend beginnt der Auswahlprozess erneut.
